# Repository purpose

This repository contains a synthetic TronClass-style student-side dataset for an AI course-assistant System 1 proof of concept.

- All people, course codes, grades, attendance records, and timestamps are simulated.
- The dataset represents one current student's view only.
- It includes course metadata, course outlines, announcements, assignments, submissions, learning materials, PDF/PPTX/DOCX attachments, extracted attachment text, quizzes, attendance records, grades, and discussions.
- `course.db` is the SQLite database used by the prototype.
- `build_db.py` rebuilds the database from files under `data/`.

Suggested initial commit message:

`Initial TronClass-style dataset for System 1 PoC`
