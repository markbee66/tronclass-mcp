## 第 1 週（9/9）課程介紹與演算法分析

### 1.1 為什麼要學資料結構
程式 = 資料結構 + 演算法。同一個問題，選擇不同的資料結構，執行時間可能從幾毫秒變成幾小時。本課程的目標是讓同學能夠針對問題特性，選擇並實作合適的資料結構。

### 1.2 時間複雜度
我們用 Big-O 表示演算法在輸入規模 n 變大時，執行步驟數的成長趨勢。常見的複雜度由快到慢為：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)。

- O(1)：存取陣列第 i 個元素
- O(log n)：在已排序陣列中做二分搜尋
- O(n)：線性搜尋
- O(n log n)：合併排序
- O(n²)：氣泡排序、選擇排序

### 1.3 空間複雜度
除了時間，演算法也會使用額外記憶體。例如合併排序需要 O(n) 的額外空間，而原地排序（in-place）的快速排序平均只需要 O(log n) 的遞迴堆疊空間。

### 1.4 課堂練習
請判斷下列程式片段的時間複雜度：兩層巢狀迴圈各跑 n 次為 O(n²)；外層跑 n 次、內層每次除以 2 為 O(n log n)。

## 第 2 週（9/16）陣列

### 2.1 一維陣列
陣列是一段連續的記憶體空間，所有元素型別相同。因為位址可以直接計算（起始位址 + i × 元素大小），所以隨機存取是 O(1)。

### 2.2 插入與刪除的代價
在陣列中間插入一個元素，必須把後面的元素全部往後移一格，最壞情況為 O(n)。刪除同理。

### 2.3 二維陣列與列優先
C 語言的二維陣列以列優先（row-major）儲存。a[i][j] 的位址為：起始位址 + (i × 欄數 + j) × 元素大小。

### 2.4 動態陣列
Python 的 list、C++ 的 vector 都是動態陣列。容量不足時會配置更大的空間（通常是兩倍）並複製元素，因此 append 的攤銷（amortized）時間是 O(1)。

## 第 3 週（9/23）鏈結串列

### 3.1 單向鏈結串列
每個節點包含資料與指向下一個節點的指標。插入或刪除已知位置的節點只需 O(1)，但要找到第 i 個節點需要從頭走訪，為 O(n)。

### 3.2 雙向鏈結串列
每個節點多一個指向前一個節點的指標，可以雙向走訪，刪除節點時不需要另外記錄前一個節點。代價是每個節點多佔一個指標的空間。

### 3.3 環狀鏈結串列
最後一個節點指回第一個節點。常用於需要循環處理的情境，例如作業系統的 round-robin 排程。

### 3.4 陣列 vs. 鏈結串列
| 操作 | 陣列 | 鏈結串列 |
|---|---|---|
| 隨機存取 | O(1) | O(n) |
| 頭部插入 | O(n) | O(1) |
| 記憶體配置 | 連續 | 分散 |

## 第 4 週（9/30）堆疊

### 4.1 堆疊的定義
堆疊（stack）是後進先出（LIFO）的資料結構，主要操作為 push（放入頂端）與 pop（從頂端取出），兩者皆為 O(1)。

### 4.2 實作方式
可以用陣列或鏈結串列實作。以陣列實作時需要一個 top 變數記錄頂端位置。

### 4.3 應用
- 括號配對檢查
- 函式呼叫堆疊
- 中序運算式轉後序運算式
- 瀏覽器的「上一頁」

### 4.4 中序轉後序
運算子依優先順序放入堆疊；遇到右括號時，把堆疊中的運算子彈出直到遇到左括號。例如 a + b * c 轉為 a b c * +。

## 第 5 週（10/7）佇列

### 5.1 佇列的定義
佇列（queue）是先進先出（FIFO）的資料結構，操作為 enqueue（從尾端加入）與 dequeue（從前端取出）。

### 5.2 環狀佇列
用陣列實作佇列時，前端取出後會留下空位，造成空間浪費。環狀佇列把陣列頭尾相接，用 (rear + 1) % n 計算下一個位置。為了區分「空」與「滿」，通常會保留一格不用。

### 5.3 雙端佇列
deque 允許兩端都能插入和刪除，Python 的 collections.deque 即為此結構。

### 5.4 優先佇列
每個元素有優先權，取出時取優先權最高者。常以堆積（heap）實作，插入與取出皆為 O(log n)，將於第 11 週介紹。

## 第 6 週（10/14）樹的基本概念

### 6.1 名詞定義
- 根（root）：沒有父節點的節點
- 葉（leaf）：沒有子節點的節點
- 深度（depth）：從根到該節點的邊數
- 高度（height）：從該節點到最深葉節點的邊數

### 6.2 二元樹
每個節點最多兩個子節點。高度為 h 的二元樹最多有 2^(h+1) − 1 個節點。

### 6.3 走訪方式
- 前序（preorder）：根 → 左 → 右
- 中序（inorder）：左 → 根 → 右
- 後序（postorder）：左 → 右 → 根
- 層序（level-order）：使用佇列逐層走訪

### 6.4 完全二元樹與陣列表示
完全二元樹可以用陣列儲存：節點 i 的左子節點為 2i + 1，右子節點為 2i + 2，父節點為 (i − 1) / 2（取整數）。

## 第 7 週（10/21）二元搜尋樹

### 7.1 定義
二元搜尋樹（BST）中，每個節點的左子樹所有值都小於該節點，右子樹所有值都大於該節點。對 BST 做中序走訪會得到由小到大的排序結果。

### 7.2 搜尋與插入
從根開始比較，小於往左、大於往右。平均時間為 O(log n)，但如果依序插入已排序的資料，樹會退化成鏈結串列，最壞為 O(n)。

### 7.3 刪除
- 刪除葉節點：直接移除
- 刪除只有一個子節點的節點：用子節點取代
- 刪除有兩個子節點的節點：用右子樹的最小值（中序後繼）或左子樹的最大值（中序前驅）取代，再刪除該值原本的節點

### 7.4 作業三說明
作業三要求實作 BST 的插入、刪除與中序走訪，並附上 README 說明刪除兩個子節點時採用哪一種取代方式。

## 第 8 週（10/28）AVL 樹與期中考複習

### 8.1 為什麼需要平衡
BST 在最壞情況會退化成 O(n)。平衡樹透過旋轉維持樹的高度在 O(log n)。

### 8.2 平衡因子
AVL 樹中，每個節點的平衡因子 = 左子樹高度 − 右子樹高度，且必須為 −1、0 或 1。插入或刪除後若有節點的平衡因子變成 2 或 −2，就需要旋轉。

### 8.3 四種旋轉
- LL 型：對失衡節點做一次右旋
- RR 型：對失衡節點做一次左旋
- LR 型：先對左子節點左旋，再對失衡節點右旋
- RL 型：先對右子節點右旋，再對失衡節點左旋

### 8.4 期中考複習重點
期中考範圍為第 1 週到第 7 週，AVL 樹（本週內容）不在期中考範圍內，會放在第二次小考。請特別複習：時間複雜度判斷、環狀佇列、BST 的插入與刪除、各種走訪順序。

### 8.5 期中考注意事項
期中考可以攜帶一張 A4 大小的手寫小抄，限單面，不可影印或列印，考後需與考卷一併繳回。不可使用計算機。
