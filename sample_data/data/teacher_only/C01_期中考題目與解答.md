# 【機密】資料結構期中考題目與解答（2026-11-04）

1. **（10 分）** 以陣列實作的堆疊，push 與 pop 的時間複雜度為何？
   **解答：** 皆為 O(1)（不考慮擴容時為 amortized O(1)）。

2. **（15 分）** 依序插入 50、30、70、20、40、60、80 到空的二元搜尋樹，請寫出中序走訪結果。
   **解答：** 20, 30, 40, 50, 60, 70, 80。

3. **（15 分）** 環狀佇列容量為 n，為何通常只能存 n−1 個元素？
   **解答：** 保留一格以區分「空」與「滿」：front == rear 表示空，(rear + 1) % n == front 表示滿。

4. **（20 分）** 以鏈結串列反轉為例，寫出迭代版本的虛擬碼。
   **解答：** 使用 prev、curr、next 三個指標，逐一把 curr.next 指向 prev，最後回傳 prev。
